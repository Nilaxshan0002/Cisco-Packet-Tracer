# Cisco Packet Tracer Projects

## Project Overview
This repository contains networking practical exercises, network simulations and configuration projects developed using Cisco Packet Tracer.

## Tools Used
- Cisco Packet Tracer

## Topics Covered
- Network Topologies
- IP Addressing and Subnetting
- Router Configuration
- Switch Configuration
- VLAN Configuration
- Routing Protocols
- DHCP Configuration
- DNS Configuration
- Network Security
- Firewall Configuration
- Network Troubleshooting

## Project Objectives
- Develop practical networking skills.
- Understand network infrastructure and communication.
- Practise router and switch configurations.
- Improve network troubleshooting abilities.
- Apply theoretical networking concepts through simulations.

## Repository Contents
This repository includes Packet Tracer project files (.pkt), network diagrams, configuration exercises and related documentation.
